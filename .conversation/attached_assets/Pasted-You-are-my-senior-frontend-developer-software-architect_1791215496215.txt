ARCHITECTURE RULES
------------------
Follow separation of concerns.

api.js:
- The ONLY place containing fetch calls.
- Use one BASE_URL constant.
- Create:
  - getAccounts()
  - getTransactions()
  - createTransaction(data)
- Check response.ok.
- Throw useful errors.

useFetch.js:
Return:

{
  data,
  isLoading,
  error,
  refetch
}

Reuse this hook across multiple pages.

Components:
- Primarily responsible for displaying UI.
- Avoid putting API calls directly inside reusable components.

Pages:
- Assemble components.
- Handle page-level state and behaviour.

utils:
- Pure reusable functions.
- Especially formatting, filtering and insight calculations.
